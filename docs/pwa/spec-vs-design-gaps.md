# Specification and design gaps

This is an implementation checkpoint, not an approved exception list. The full source is preserved in `master-specification.md`. All 61 supplied images were inspected and mapped in `design-reference-map.md`. The inventory includes all 95 numbered Appendix targets, checkout/resale, concrete workspace Agent states, existing authentication/Admin integrations and both studios. Route presence does not establish complete state or capability coverage.

| Requirement / discrepancy | Implemented treatment | Remaining gate |
|---|---|---|
| References show inconsistent sidebars and five direct destinations | Four role-specific primary destinations plus rightmost Menu below 1280px; native three-column modal sheet. Desktop navigation retained. | Full per-route capability variants, installed mode and physical device checks. |
| Artwork includes phone bezels, OS indicators and miniature typography | No decorative device chrome in app; readable type, 44px shared controls and safe-area padding. Comparison crops recorded separately. | Reviewed stable regions and bounding boxes for every reference; no blanket visual exception approved. |
| Several alternate designs for one page | Primary and alternate images retained; discovery montage identified separately. | Capture and assess each relevant view; a montage cannot count as one fidelity pass. |
| Unpictured wizard steps and overlays | Reuse actual existing forms, domain actions and shared visual tokens. Individual sourced steps remain in manifest. | Interaction, validation, back/resume, permission and responsive evidence for every state. Absence of an image is not a quantified visual pass. |
| Canonical professional ticket setup has three source steps; existing engine exposes five | Preserve real seating, rules and review engine rather than remove supported workflow. | Explicit source-step mapping and behavior review needed; this discrepancy remains open. |
| Media Studio has no standalone supplied PWA screenshot | Reuse canonical `/studio/[id]`, existing design document/export engine and asset-library reference. Added touch layout, optional inspector and native creation modal. | Full save/reload/export, upload, quotas, permission variants, keyboard and text-scaling tests. |
| Event Map Studio | Reuse event map route and shared venue-plan engine, mapped to ORG-013. Added touch toolbar and short-landscape reflow. | Full geometry, save/reload, seating/GA integration, concurrent editing, export and all capability variants. |
| Durable Agent concrete routes missing | Added Organizer/Provider run-detail routes and routines/approvals/history aliases using existing runtime, RLS and actions. Credits now come from the authoritative balance RPC. | Full Agent mission, approval, retries, notification, reversal and complete surface/capability matrix. A separate Customer chatbot was not invented. |
| Screenshot sample names, budget values and payout promises | Actual authorized records and domain arithmetic prevail. Removed hardcoded Agent budget and unsupported resale payout-to-original-method promise. | Deterministic authorized fixtures for visual comparisons; actual resale payout destination and settlement readiness remain unverified. |
| Resale cap could advertise less than immutable ticket face price while charging face price | Listings and holds consistently use face price and reject a configured cap below it; enforce platform/event policy, event window and ticket state. | Adjustable resale pricing is not introduced. Complete payout, refund, cancellation and settlement flows still require verification. |
| Existing shared workspace continues changing in other sessions | Preserve those edits; isolated build directory and separate test output directories used. | Repeat final checks against an immutable release candidate. Latest evidence is a checkpoint of a changing tree. |

No screenshot embellishment was treated as authorization to invent financial calculations, a payout schedule, new providers, canned Agent results or dummy backend behavior. No unverified route is marked completed. The 5% threshold is unchanged.
