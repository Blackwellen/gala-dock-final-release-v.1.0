## Latest user scope correction

The user explicitly accepted that exact 1:1 matching may be impossible and requested maximum implementation of all PWA pages. Functional coverage, usable responsive states, integrations and security remain required. The original 5% pixel threshold is retained as a historical measurement, but is no longer by itself a reason to describe implemented pages as absent or stop functional completion. This does not waive financial correctness, authorization, accessibility or workflow verification. See `maximum-functional-assessment.md` for the current assessment rather than interpreting the older all-gates completion count as a count of missing pages.
